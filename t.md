Да, интерпретатор Python скачать придётся в любом случае. [2]
Сам Sublime Text и плагины для него (LSP, Anaconda) — это просто текстовые редакторы. Они не умеют «читать» код и понимать, какие методы есть у библиотек. Чтобы автокомплит заработал, плагину нужен именно движок Python (python.exe), который запустится в фоновом режиме, импортирует файлы из вашей папки dist-packages и построит по ним карту подсказок.
Поскольку вам нужен только автокомплит на Windows для Linux-пакетов, ваш идеальный минимальный план выглядит так:

1. Скачайте самый легкий Python для Windows

Вам не нужно полноценно настраивать менеджер пакетов pip и что-то скачивать, раз папка с кодом уже есть.
1. Скачайте Windows embeddable package (64-bit) (архив весит всего около 10 МБ).
2. Распакуйте его в любую папку (например, C:\PythonPortable\).

2. Подключите вашу папку dist-packages в Sublime Text

Самый чистый способ, чтобы не трогать системные файлы Python — указать путь к вашей Linux-папке прямо в настройках плагина автокомплита в Sublime Text.
• Если вы выбрали плагин Anaconda:
Зайдите в Preferences -> Package Settings -> Anaconda -> Settings - User и укажите пути к скачанному Python и к вашей Linux-папке:json
{
    "python_interpreter": "C:/PythonPortable/python.exe",
    "extra_paths": [
        "C:/Путь_К_Вашей_Папке/dist-packages"
    ]
}
Используйте код с осторожностью.
• Если вы выбрали плагин LSP (LSP-pylsp):
Зайдите в настройки LSP-pylsp и добавьте путь в секцию extra_paths языкового сервера.
При такой настройке фоновый Python на Windows успешно распарсит все текстовые .py файлы из вашей Linux-папки и выдаст по ним подсказки, а вам не придется захламлять систему полноценной установкой.
Если у вас возникнут трудности с заполнением файла настроек .sublime-settings, пришлите:
• Точный путь, куда вы распакуете портативный Python.
• Точный путь к вашей папке dist-packages.
